# Security policy

## Supported versions

Only the latest release of DMARC Checker receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's [private vulnerability reporting](https://github.com/ksanyok/dmarc-checker/security/advisories/new)
or write to info@promopilot.link. You will get a reply within 72 hours.

This tool runs locally on your machine; it does not send your data anywhere
except to the hosts you ask it to check.
